## Replacing one

Save the replacement at the same filename and roughly the same aspect ratio,
and drop it into `assets/images/staff/`. Nothing in the HTML or the JSON needs
editing — but do check the `alt` text still describes the new scene, because
alt text that has drifted from its image is worse than no alt text at all.

The one image worth replacing first is `staff-pest.jpg`, which is the only
sourced photograph on the site. See `assets/images/CREDITS.md`.
